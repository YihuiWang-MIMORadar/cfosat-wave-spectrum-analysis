# CFOSAT Wave Spectrum Analysis

Python workflows for processing and analyzing CFOSAT/SWIM ocean wave spectrum data.

## Project Structure

- `src/`: core source code
- `scripts/`: executable analysis scripts
- `configs/`: configuration files
- `docs/`: documentation
- `tests/`: tests
- `sample_data/`: small example data
- `results/`: figures and outputs
- `notes/`: research notes

## Data

The full CFOSAT/SWIM datasets are not included in this repository due to their large size.

Local data paths should be configured in:

`configs/paths.yaml`

Use `configs/paths.example.yaml` as a template.
